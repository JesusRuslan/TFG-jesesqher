\chapter*{Resumen}
Este proyecto tiene como objetivo mejorar la precisión y eficiencia de la navegación SLAM (Simultaneous Localization and Mapping) en un robot móvil, utilizando una combinación de sensores integrados y externos. Se empleará ROS2 (Robot Operating System) para gestionar el comportamiento del robot.

A diferencia de otros estudios, además del sensor integrado en el robot, se utilizará una estación externa (PC) con un sensor adicional (LIDAR o cámara estereoscópica) para detectar al robot y establecer una comunicación robot-PC, optimizando la precisión y rapidez en la creación de mapas en tiempo real.
